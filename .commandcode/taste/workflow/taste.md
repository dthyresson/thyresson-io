# Workflow

- When brainstorming copy, wording, or example/story choices, wants multiple candidate options presented as a list for review (e.g. "3 examples per session", "list and i'll pick") with no file edits yet — hold the edits until he picks one. Confidence: 0.8
- Prefers the simpler git setup: when work is related, keep it together on the existing branch/PR ("lets just add this work to the post branch too and work all in there") instead of splitting it into separate branches and PRs. Rejects "too complicated" multi-branch/branch-churn workflows. Confidence: 0.6
- When iterating on a creative asset he already likes, wants it preserved as-is and the tweak produced as a new versioned variant ("i like both-medallions-1200x630 but keep this make a v2") instead of editing the approved file in place. Confidence: 0.55
- When iterating on a design he already approved, wants each new version to change only the one thing he asked about and leave the rest of the layout untouched — declined the re-conceptualized variants (new background fields) with "no i still like original ... so for v5 just make medallions smaller". Confidence: 0.6
- When shared copy (descriptions, abstracts) changes, wants derived artifacts that quote it (e.g. the `artwork/summit-one-pager` HTML + markdown one-pager) updated in sync rather than left stale with the old wording. Confidence: 0.5
- Wants the site package version actually bumped as work lands (e.g. `thyresson-io` 0.0.1 → 0.1.0), and semver maintained going forward: minor bump for a batch of features/work, patch for fixes — "for changes bump minor or patch as needed". Confidence: 0.5
- Expects the repo's standard scripts (notably `pnpm preview`) to actually work as a faithful preview of the built production site — "preview should work but it does not". A dev-server-only path or a hand-rolled static file server that can't reproduce the host's redirects/functions/image CDN is not an acceptable substitute; fix the root cause with the platform's own tooling (e.g. adding `netlify-cli` and running `netlify serve`) rather than shipping a workaround. Confidence: 0.6
