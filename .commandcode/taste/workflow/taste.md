# Workflow

- When brainstorming copy, wording, or example/story choices, wants multiple candidate options presented as a list for review (e.g. "3 examples per session", "list and i'll pick") with no file edits yet — hold the edits until he picks one. Confidence: 0.8
- Prefers the simpler git setup: when work is related, keep it together on the existing branch/PR ("lets just add this work to the post branch too and work all in there") instead of splitting it into separate branches and PRs. Rejects "too complicated" multi-branch/branch-churn workflows. Confidence: 0.6
- When shared copy (descriptions, abstracts) changes, wants derived artifacts that quote it (e.g. the `artwork/summit-one-pager` HTML + markdown one-pager) updated in sync rather than left stale with the old wording. Confidence: 0.5
